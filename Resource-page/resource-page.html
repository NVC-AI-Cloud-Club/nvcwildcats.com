HOW THE DEVOPS TOOLS FIT TOGETHER

Four tools. Four different jobs.

These tools often appear together in cloud and DevOps projects, but they solve different problems.

01

Terraform

Provision the infrastructure

Defines and creates resources such as networks, servers, storage, and cloud services using Infrastructure as Code.

“Build the environment.”
Watch video 1 ↗Watch video 2 ↗
02

Ansible

Configure the systems

Automates setup tasks on servers: install packages, create users, manage files, and apply repeatable configurations.

“Set up the machines.”
Watch video 1 ↗
03

Docker

Package the application

Bundles an application and its dependencies into a container so it can run consistently across environments.

“Package the app.”
Watch video 1 ↗
04

Kubernetes

Run and manage containers

Coordinates containers across a cluster, handling deployment, scaling, service discovery, and recovery.

“Operate containers at scale.”
Watch video 1 ↗Watch video 2 ↗

A common learning sequence is Linux and networking basics → Git → Docker → Kubernetes, while learning Terraform and Ansible as infrastructure automation skills. Real projects may use these tools in different combinations.
