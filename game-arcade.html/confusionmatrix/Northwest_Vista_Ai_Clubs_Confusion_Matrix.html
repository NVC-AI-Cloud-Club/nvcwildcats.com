What Is Bayes Theorem?

Bayes Theorem lets us update our belief about something based on new evidence. In machine learning, confusion matrices contain all the numbers we need to compute Bayesian probabilities.

The classic formula: P(Disease | Positive Test) = P(Positive | Disease) × P(Disease) / P(Positive)

Every one of these probabilities can be read directly from a confusion matrix — and that's exactly what you'll do in Phase 3!

Key Connections: Matrix → Bayes
Sensitivity (Recall) TP / (TP+FN) = P(+ Test | Has Disease)
Specificity TN / (TN+FP) = P(− Test | No Disease)
Prevalence (TP+FN) / Total = P(Disease)
PPV (Precision) TP / (TP+FP) = P(Disease | + Test)
NPV TN / (TN+FN) = P(No Disease | − Test)

What You Mastered

You now understand that confusion matrix values aren't just numbers — they're probabilities waiting to be unlocked by Bayes Theorem. Every TP, FP, TN, FN maps directly to a conditional probability.

Sensitivity = Recall = P(+ | Disease). Specificity = P(− | No Disease). PPV = Precision = P(Disease | +). These are the building blocks of real-world diagnostic reasoning.
